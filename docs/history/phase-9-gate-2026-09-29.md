runs on the mock backend with the API keys removed from its environment, per
the rule that benchmarks never use a paid API. The telemetry and runbook
lines used a few gpt-4o-mini calls, as earlier gates did.

answered the install prompt a second time, and that stray `y` went to the
shell. The helper now only answers prompts that arrive after its last answer.
