Set up testing on Windows

Sable is a Linux login shell. On Windows it runs inside the Docker playground, which bind-mounts this repo, so edits in VS Code show up live. Only the unit tests run natively.

  1. Install Docker Desktop (it brings WSL2), reboot, then confirm it works.

    winget install Docker.DockerDesktop
docker version

  2. Create .env in the repo root (c:\Parth\Projects\Anonymous\Sable\.env, next to .env.example). Both playground launchers read it and forward it into the container. It is gitignored.

    cd c:\Parth\Projects\Anonymous\Sable
copy .env.example .env

  3. Fill in your OpenAI details. Only the key for your chosen backend is needed. A variable already set in your PowerShell session wins over the file.

    SABLE_BACKEND=openai
SABLE_MODEL=gpt-4o-mini
OPENAI_API_KEY=sk-...
# SABLE_MOCK_LLM=1   ← uncomment for free, canned runs with no API calls

  4. Build once, then launch. The first build takes a few minutes.

    .\scripts\playground.ps1 -Rebuild   # one time
.\scripts\playground.ps1            # interactive Sable shell in tmux
.\scripts\playground.ps1 tests      # unit tests inside Linux
.\scripts\playground.ps1 bash       # plain bash: inspect ~/.sable, sqlite, audit.log

  5. Reset when state gets messy. Wipes config, sqlite, tasks and skills in the container.

    docker volume rm sable-playground-home
